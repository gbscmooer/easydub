### 结论（论文 5 章 / 简历可直接引用）

1. **消融梯度成立**：纯自然翻译溢出率 22%~100%（中→英信息密度差 + 短槽位）；
   +限长创译降到 0~50%；+atempo 再降；**+溢出重译闭环后在全部素材上 0%**。
   一句话：溢出率 38%~100% → **0%**。
2. **云 TTS 静音修剪是隐性关键项**：edge-tts 固定 ~0.2s 头静音 + 最长 1s 尾静音，
   不修剪时短句对齐全毁（实验记录见 EDPLAN §6）。
3. **低 BGM 鲁棒**：-26dB 正弦底噪下 CER 0.17，与无 BGM 素材同水平，流水线不退化。
4. **成本**：合成素材单条 ¥0.012~0.028（免费 TTS 通道），远低于 ¥1 合格线；
   云 ASR 占成本大头，本地 whisper 档可进一步压到 ~0。
5. **速度**：RT 系数 0.3~1.9（不含 lip-sync），远低于 10× 合格线；
   c4 人脸素材不开口型时 0.56。

## 第二轮自主优化（2026-09-06，de50a02 / 1b94704 / 7b1ebd2）

| 项 | 内容 | 实测收益 |
|---|---|---|
| **BGM 保留 + 自动闪避** | 原实现把原视频音频整条丢掉；现以配音为 sidechain 触发信号，`sidechaincompress` 闪避混入原声，句间自动抬回 | Nike 广告句间 -91dB（死寂）→ -29dB（音乐回归）；说话中配音电平 -26.7 → -26.6dB（几乎不受影响） |
| **spill 溢出重分类** | 借句间空隙能容纳的溢出不算真冲突，不烧重译 | Nike 段10（0.24s 槽位）原每次重跑烧 2 轮 LLM → 0 调用；es 全绿 |
| **实测语速校准** | 重译字符预算按本次 TTS 实测语速中位数收紧（只下修、60% 表值下限），替代静态 CPS 表 | 换 TTS 供应商预算不漂移；c1 es 溢出段实测 8.5 cps vs 表值 14，暴露并解释了旧预算失效根因 |
| **重译止损** | 本轮无净减少溢出即提前退出 | 预算到垫尾极限时不再空转 |
| **TTS/重译并发** | 未命中缓存的合成与重译轮内多段 LLM 调用走线程池（4 并发） | edge-tts 13 段：串行 20.0s → 4.7s（**4.3×**） |

方法注意：闪避测试里 ffmpeg `sine` 源默认振幅仅 ~0.09（-21dB），测试配音
必须高增益才能触发深压缩——这是频段测量法（bandpass 隔离 BGM 频率）能
量化的前提，测试代码有注释。
